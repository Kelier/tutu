# 蜡笔抖抖 · Crayon Boil

把图片 / 视频实时重绘成「手绘蜡笔 + 6fps 抖动」风格（参考 Charlie Jones 风格的 AE 动画），导出 3 秒 GIF 与透明贴纸。全部在浏览器本地用 WebGPU 完成，素材不上传。

## 运行

```bash
npm install
npm run dev                    # 开发
npm run build && npx vite preview --port 5226   # 线上：gzip（wasm 13MB → 3.8MB）+ 长缓存
npm run qa                     # 无头 Chromium：首屏/样式检查 + 14 个模板出图 + 漫画加料 + GIF 导出到 qa/
```

## 加载优化

- 样式在 `<head>` 用 `<link>` 引入，首屏前就生效，不再出现无样式闪烁；首帧前显示启动屏（连接 GPU → 编译着色器 → 载入示例 → 渲染第一帧）
- GPU 初始化与示例图下载并行；示例图 `<link rel="preload">`
- 合成着色器用 WGSL `override` 常量按模板特化，**只先编译当前模板**，其它模板在空闲时异步编译
- 主体识别（MediaPipe，模型和 wasm 本地托管）首帧后再加载，代码拆包懒加载
- 模板缩略图：可见时才渲染，空闲时一张一张来，只重跑量化不重跑去细节
- 预览只在帧号 / 尺寸 / 参数变化时重画（动画本身是 12.5fps 的步进），GPU 留给编译、缩略图和导出
- GPU 任务（缩略图、导出、识别）串行加锁，避免互相改状态

需要支持 WebGPU 的浏览器（Chrome / Edge 113+，Safari 26+）。

## 风格模板（src/templates.ts）

同一条预处理管线，换一个合成分支 + 色板 + 参数就是一个新模板（共 14 个）：

| 模板 | 合成方式 |
|---|---|
| 粉笔黑板 | 深色黑板 + 擦痕 + 粉笔粗颗粒排线，亮处粉笔更密 |
| 霓虹描边 | 只画色块边界，近处灯芯 + 远处光晕，按 boil 随机闪烁 / 偶尔灭一根 |
| 剪纸拼贴 | 每个色块按 boil 轻微错位，上层纸片露撕边白芯并投影 |
| 刺绣 | 每块不同方向的缎面针脚（线的圆柱高光）+ 布纹 + 回针描边 |
| 复古报纸 | 单色 45° 网点，网点半径加噪声模拟油墨晕染，发黄纸 + 污渍 |
| 水彩 | 噪声扭曲做湿边扩散，色块边缘积色加深，纸纹颗粒，铅笔底稿 |
| 油画厚涂 | 方向场 LIC：颜色沿形体方向抹开 + 笔刷纹理 + 屏幕空间法线做厚涂高光 |
| 版画木刻 | 白噪声沿方向场 LIC 成刻线，按明暗阈值决定刻线粗细 |
| 蜡笔抖抖 | 蜡笔排线 + 纸纹拖痕 + 抖动描边 + 暗部交叉排线 |
| 儿童涂鸦 | 同上，更大色块、更粗轮廓、抖得更凶 |
| 漫画线稿 | 墨线 + 三阶 45° 网点 + 暗部涂黑 |
| 波普网点 | 高饱和平涂 + 本戴点 + 暗部黑点 + 粗黑线 |
| 孔版印刷 | 粉 / 蓝 / 黄三色分色 + 网点颗粒，套色错位随 boil 抖动 |
| 像素贴纸 | 像素网格 + PICO-8 16 色 + Bayer 有序抖动 + 硬边描线 |

模板卡片的缩略图是用当前素材实时渲染的。

## 复杂照片：主体清晰（src/detect.ts）

- MediaPipe（wasm 和模型都放在 `public/mediapipe/`，本地加载）识别人物/动物和人脸；人物框上部会放大后再找一次，小脸也能找到
- 焦点内：Kuwahara 半径变小、跳过众数滤波、抖动减半、细节线增强
- 人脸内：只保留最强的五官线、肤色提亮、减少暗部排线，避免糊成一团
- 背景：半径加大，有焦点时线更少、对比降低（“背景退后”）
- 「明暗保留」：按原图明度在色块上叠加暗部交叉排线 / 高光留白，保住形体
- 也可以点「设焦点」手动指定

## 漫画加料（src/overlay.ts + shader）

- 集中线（以人脸为中心）/ 速度线（只画在背景上）：shader 里按 boil 抖动
- 拟声字、对话气泡：Canvas2D 画在输出尺寸上，气泡尾巴自动指向人脸，按 boil 抖动后作为纹理合成；贴纸模式下也会扩展透明区域

## 五官重绘

识别到人脸后，用 BlazeFace 关键点（双眼、嘴）在脸上平涂肤色，再画点眼睛 + 高光、上扬弧线嘴、腮红和脸部轮廓，专治小脸看不清。

## 画面后期（src/post.ts + fs_final）

「后期」页提供 15 种 GPU 处理，叠加在任何风格模板上，按 uniform 切换、不重新编译着色器，预览和全部导出一致：

| 类型 | 处理方式 |
|---|---|
| 色彩 | 胶片颗粒、暗角聚光、双色调（墨 → 投影色 → 纸）、色调分离（4 阶 + Bayer 抖动）、漏光、热成像、蓝晒、褪色宝丽来（带相纸边框） |
| 质感 | CRT 扫描线（弯曲 + RGB 荧光格）、纸张折痕、浮雕（明度梯度打光） |
| 几何 | 镜像对称、万花筒（六瓣）、鱼眼、水波纹 |

动态类（颗粒、漏光、万花筒、水波纹、CRT 闪烁）跟随 boil 步刷新，和抖动节奏一致。文字叠加层在后期之后合成，不会被扭曲。

## 字体排版模板（src/typography.ts）

「文字」页有 30 个排版模板，分为标题 / 古典 / 手账 / 海报 / 漫画 / 实验六类；卡片用当前文字实时渲染，每页 6 张小样，支持分类筛选、Roll、撤销套用、还原排版与显式拖动画面文字；点一下即套用（保留用户文字）。细调里可换 8 种字体、9 种布局（横排、竖排、弧形、整圆、波浪、散落、斜排、阶梯、主副标题）和 12 种效果（实色、空心、贴纸白边、立体投影、霓虹、蜡笔抖动、荧光笔、字幕条、朱红印章、双色套印、数字故障、数字矩阵）。

## 渲染管线（src/shaders.ts）

| Pass | 作用 |
|---|---|
| `fs_kuwahara` ×2 | 去掉照片细节，变成色块（焦点处半径小，背景处半径大） |
| `fs_edge` | 高斯差分细节线 + 平滑后的 Oklab 明度（给明暗保留、网点用） |
| `fs_quant` | Oklab 空间映射到 16 色蜡笔盒 / 自动色板；视频帧带滞回，色块不乱跳 |
| `fs_mode` ×2 | 5×5 众数滤波，清掉零碎色块 |
| `fs_tensor` / `fs_flow` | 结构张量 → 方向场（油画、版画用） |
| `fs_final` | 按模板合成（见上表）+ 投影 + 贴纸白边 + 动作 |

抖动（boil）：所有噪声种子由 `boil = floor(frame / boilEvery)` 驱动，默认 12.5fps 输出、每 2 帧换一次纹理，约 6 次/秒，和参考视频一致；种子对 3 秒取模，GIF 首尾无缝循环。

## 主体分离（src/mask.ts）

无模型版：四条边采样背景色（与其余三边不一致的边视为主体贴边，例如半身像底边）→ 洪水填充（不跨越强边缘）→ 去碎块 → 羽化。PNG 透明图直接用 alpha。复杂背景会自动判定为不可分离。

## 导出（src/gif.worker.ts）

- 跨帧采样建一张全局调色板，避免 GIF 闪烁
- 合并完全相同的相邻帧（静态图 + 每 2 帧 boil 时体积约减半）
- 帧间差分：不变像素写成透明索引
- 贴纸：1 位透明 + 白色描边，尺寸 240（微信表情）/ 320 / 512

## 艺术字体与移动端动态导出

明朝、Noto Serif SC、马善政字体在本地按需加载，完整 OFL 授权与来源见 `public/fonts/`。同一叠字管线用于预览和全部导出。

动态格式：GIF（支持透明）、MP4（不透明 H.264）、安卓 Motion Photo（单文件 `*MP.JPG`，含标准 XMP 目录与附加 MP4）、Apple Live Photo ZIP（同 UUID 的 JPG + MOV，以及 still-image-time 的 mebx 定时元数据轨）。浏览器无法直接将 Apple 配对资源写入 iOS 相册为 Live Photo，需使用支持配对导入的工具；导入说明也在 ZIP 内。安卓相册和社交平台对导入的识别因设备和版本而异。下载/分享原文件，避免聊天应用重新压缩。

视频优先使用 WebCodecs H.264；不支持时按需加载本地 FFmpeg WASM（首次约 32MB）。GIF 不依赖此下载。所有导出均在浏览器本地进行。WASM 可能受移动端内存限制，失败时可降低尺寸和帧率。

验证脚本：`node scripts/workbench-qa.mjs`（30 种模板可达性 / 分类 Roll / 撤销 / 还原 / 合成触控拖字 / 15 种后期像素差异 / GIF 与 Live 导出 / 多尺寸无横向溢出）；`node scripts/features-qa.mjs`（GPU / 排版 / 三种动态格式）；`node scripts/software-video-qa.mjs`（关闭 VideoEncoder 验证 WASM 回退）。浏览器验证使用 Chromium 与合成触控；未代替 iPhone / Android 真机的相册导入验证。
